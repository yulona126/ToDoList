# ToDoList · 设计系统（黑白极简）

设计目标：**像一把好用的工具，而不是一个要你欣赏的产品**。信息密度优先，装饰最少，
所有视觉手段都服务于"扫一眼就知道现在该做什么"。

---

## 1. 设计令牌

令牌以 CSS 自定义属性定义在 `frontend/src/index.css`，Tailwind v4 通过 `@theme` 映射为工具类。
**所有组件必须使用令牌，禁止硬编码颜色值。**

```css
:root {
  --bg:            #ffffff;   /* 页面背景 */
  --surface:       #ffffff;   /* 卡片/面板背景 */
  --surface-muted: #fafafa;   /* 次级背景（hover/隐藏区） */
  --fg:            #0a0a0a;   /* 主文字 */
  --fg-muted:      #737373;   /* 次要文字、元信息 */
  --fg-subtle:     #a3a3a3;   /* 占位符、禁用 */
  --border:        #e5e5e5;   /* 常规描边 */
  --border-strong: #d4d4d4;   /* 强调描边 / hover 描边 */
  --fg-inverse:    #ffffff;   /* 反色文字（黑底按钮上） */
  --accent:        #0a0a0a;   /* 主色=近黑 */
}
.dark {
  --bg:            #0a0a0a;
  --surface:       #141414;
  --surface-muted: #1c1c1c;
  --fg:            #fafafa;
  --fg-muted:      #a3a3a3;
  --fg-subtle:     #6b6b6b;
  --border:        #262626;
  --border-strong: #404040;
  --fg-inverse:    #0a0a0a;
  --accent:        #fafafa;
}
```

### 尺度

| 项 | 值 |
| --- | --- |
| 圆角 | 控件 `8px`，卡片/模态 `12px`，胶囊 `999px` |
| 边框 | 恒为 `1px solid var(--border)`；不使用阴影表达层级（模态除外） |
| 阴影 | 仅模态/下拉：`0 8px 24px rgb(0 0 0 / 0.08)` |
| 间距 | 4px 栅格：`4/8/12/16/24/32` |
| 字号 | `12px` 元信息 / `13px` 次要 / `14px` 正文 / `16px` 卡片标题 / `20px` 页面标题 |
| 行高 | 正文 `1.5`，标题 `1.3` |
| 动效 | `150ms ease-out`（透明度、位移 2px）；`prefers-reduced-motion` 时禁用 |

## 2. 无彩色状态表达

黑白界面最大的风险是"状态无法区分"。对策：**用形状、填充度与文字，而不是颜色**。

| 状态 | 视觉表达 |
| --- | --- |
| `todo` | 空心圆 `○` + 常规字重 |
| `doing` | 半填充圆 `◐` + 常规字重 |
| `blocked` | `!` 前缀 + 卡片左侧 `3px` 实心黑边 |
| `done` | 实心圆 `●` + 标题删除线 + 整行 `opacity: .55` |

| 优先级 | 视觉表达 |
| --- | --- |
| `urgent` | 实心方点 ■ + 小号大写文字 `URGENT` |
| `high` | 半实心 ▲ |
| `medium` | 描边 ▲ |
| `low` | 无任何标记（保持安静） |

| 任务类型 | 图标（内联 SVG，统一 14px 线性风格） |
| --- | --- |
| `dev` | `</>` |
| `meeting` | 日历 |
| `communication` | 对话气泡 |
| `design` | 方框+圆 |
| `research` | 放大镜 |
| `other` | 圆点 |

逾期：`due_date` 以 `font-weight: 600` + 前置 `⌛` 表达，**不使用红色**。

## 3. 组件规范

### Button

| 变体 | 样式 | 用途 |
| --- | --- | --- |
| `primary` | 黑底白字（暗色反相），hover `opacity .9` | 每屏最多 1 个 |
| `secondary` | 白底 + 描边 | 默认操作 |
| `ghost` | 无底无描边，hover `--surface-muted` | 工具栏、图标按钮 |
| `danger` | 白底 + 描边，文字 `--fg`，hover 描边加深 | 删除（不用红色） |

尺寸：`sm` 28px 高 / `md` 32px / `lg` 36px。图标按钮为正方形。
禁用：`opacity .5` + `cursor: not-allowed`。
必须支持 `loading` 态（内联 spinner，宽度锁定避免跳动）。

### Input / Textarea / Select

高度 32px，`1px` 描边，`--bg` 背景；focus 时描边变 `--fg` + 外环 `2px --border-strong`。
不用彩色 focus 环。错误态：描边加粗为 `2px --fg` + 下方 12px 错误文案。

### Modal

居中，最大宽 `480px`（表单）/ `640px`（详情）；遮罩 `rgb(0 0 0 / .4)`；
标题 16px 600，右上角关闭图标；底部操作右对齐（取消在左，主操作在右）；
`Esc` 关闭、点击遮罩关闭、打开时锁定 body 滚动、焦点陷阱。

### Checkbox

20px 圆形复选框（任务用），未完成=空心描边，完成=实心填充 + 白色对勾。
点击后触发 `toggle`，**乐观更新**（立即变灰划线，失败回滚 + Toast）。

### 空状态 EmptyState

居中，`--fg-subtle` 的 32px 线性图标 + 一句主文案 +（可选）一个主操作按钮。
文案要有引导性，例如「还没有任务 · 按 `N` 新建第一条」。

### 筛选工具栏 TaskFilters

**布局预算：默认 1 行，筛选生效时 2 行。** 这是硬约束 —— 早期版本把 6 个
`Select` 平铺成 6 行（每个都占满整宽），是整个界面最丑的地方。

```
row 1（恒定）  [全部|待办|进行中|受阻|已完成]  [▽ 筛选 ②]  [手动排序 ▾]  ···  [＋清单] [☑]
row 2（仅筛选生效时）  [优先级 · 紧急 ✕] [截止日 · 逾期 ✕] [搜索 · PWA ✕] 清除全部 ··· 共 0 项
```

规则：

| 项 | 规则 |
| --- | --- |
| 状态 | 分段控件（segmented），唯一常驻的筛选面，因为使用频率最高 |
| 优先级/类型/标签/截止日 | 收进「筛选」弹出层，**不占布局高度** |
| 弹出层 | 浮层而非展开面板；关闭不产生布局位移。`< 640px` 时状态与排序也移入其中 |
| 激活计数 | 以黑底白字胶囊显示在「筛选」按钮上（design-system §2：用填充而非颜色） |
| 激活条件 | 以可移除 chip 呈现，chip 内用「面 · 值」，✕ 单独 16px 命中区 |
| 结果计数 | **仅在筛选生效时出现**。工作区总览已给出全局计数，两者统计口径不同（此处只算顶层任务），同时常驻会自相矛盾 |
| 新增清单 / 批量选择 | 图标按钮（28px），带 `aria-label` 与 `title` |
| 排序 | 常驻 `Select`（124px），因为它改变的是视图而非过滤条件 |
| 窄屏 | 允许换行为 2 行，但**不允许**把某个控件拉满整宽 |

## 4. 布局

### AppShell

```
┌────────────┬──────────────────────────────────────────┐
│  Sidebar   │  Topbar   [工作区名]        [搜索][主题][头像] │
│  240px     ├──────────────────────────────────────────┤
│            │                                          │
│  ● 工作区 A │   Content（铺满主栏，左右 gutter 12–16px） │
│  ○ 工作区 B │                                          │
│            │                                          │
│  ──────    │                                          │
│  ⚙ 设置     │                                          │
└────────────┴──────────────────────────────────────────┘
```

- Sidebar：工作区切换（含 `stats.todo` 徽标）、新建按钮、底部设置入口。
- `< 768px`：Sidebar 变为抽屉（汉堡按钮打开，遮罩关闭）。
- 内容区不设最大宽度，随主栏铺满；左右仅保留小 gutter（约 12px / `md` 起 16px），方便架构图与任务板用满横向空间。

### 任务行（列表视图）

```
[○]  任务标题 ···························  [▲] [</>]  [tag]  02-20  [⋯]
      └ 1/2 子任务                                        (done 时删除线)
```

- 单行高度 `44px`，hover 时 `--surface-muted` 背景 + 右侧操作显现。
- 点击标题区 = 打开编辑模态；点击圆点 = 切换完成。
- 排序：默认 `sort_order`，可按截止日/优先级切换。

## 5. 键盘与效率

| 快捷键 | 行为 |
| --- | --- |
| `N` | 新建任务（焦点进标题输入框） |
| `/` | 聚焦搜索框 |
| `Esc` | 关闭模态 / 清空搜索 |
| `Cmd/Ctrl + Enter` | 在表单内提交 |
| `G` 然后 `S` | 跳转设置（可选，V1.1） |

快捷键在输入框内不触发。

---

## 6. 可访问性

- 所有可交互元素 `:focus-visible` 显示 `2px` 外环，`outline-offset: 2px`；
- 图标按钮必须有 `aria-label`；
- 模态使用 `role="dialog" aria-modal="true"`；
- 对比度：`--fg` on `--bg` ≈ 19:1，`--fg-muted` on `--bg` ≈ 4.6:1（达标）；
- 不依赖颜色传达信息（见 §2）。

## 7. 文案语气

- 中文简洁、动词开头：「新建任务」「标记完成」「删除工作区」。
- 破坏性操作必须写明后果：「删除后该工作区下的 24 条任务将一并移除，无法恢复。」
- 空状态给下一步动作，不给安慰语。
- 英文版使用句式一致的短句（`New task` / `Mark as done`），不逐字直译。
